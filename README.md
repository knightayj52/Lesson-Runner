# 수업 실행 도우미 v2.0

단원 설계안을 오늘의 수업, 복습, 수업 자료와 관찰 기록으로 연결하는 교사용 웹앱입니다.

## 사용 흐름

1. **예시 체험 또는 새 단원**: 키 없이 8차시 예시와 활동지를 둘러볼 수 있습니다.
2. **설계안 입력**: PDF·TXT·MD 또는 본문을 넣고 학년, 교과, 수업 시간, 성취기준 원문을 확인합니다.
3. **AI 연결**: Gemini 또는 Claude 키와 모델을 선택하고 연결을 확인합니다. Gemini 모델 목록은 API에서 조회할 수 있습니다.
4. **분석 검토**: 중심 아이디어, 질문, 활동, 준비물, 핵심 배움과 선수지식 연결을 직접 수정합니다.
5. **일정 확정**: 시작일, 요일, 휴업일과 복습 간격을 적용합니다. 차시 날짜를 하나만 또는 이후 차시와 함께 이동할 수 있습니다.
6. **오늘의 수업**: 질문과 준비물을 확인하고 수업 진행 화면을 엽니다. 타이머는 기본 4단계 흐름이며 수업에 맞게 시간을 조절합니다. 학생 화면에서는 교사용 메모가 제거됩니다.
7. **자료 보관함**: 과정안·활동지·배움공책·PPT를 생성합니다. 본문 수정은 자동 저장됩니다. 인쇄/PDF, 워드 호환 HTML(.doc), 서식 복사, PPT 및 개요 복사를 지원합니다.
8. **수업 기록**: 완료·미실시·보충 필요 상태와 학생 반응, 다음 수업에서 이어갈 내용을 남깁니다.

## 저장과 기존 작업

- 여러 단원을 이 브라우저의 localStorage에 저장합니다. 기기 간 자동 동기화는 없습니다.
- 원문·성취기준·시간표·자료·수업 기록을 JSON으로 백업할 수 있습니다. 키는 백업에 포함하지 않습니다.
- v1.1의 `lr_state` 및 기존 JSON을 읽습니다. 이전 버전에 없던 원문과 시간표 설정은 다시 확인해야 합니다. 기존 저장 키는 자동 삭제하지 않습니다.
- 재분석 시 기존 분석 단원과 자료를 보존하고 새 분석본을 만듭니다. 동일 ID의 파일을 다시 가져오면 사본으로 저장합니다.
- 브라우저 저장 공간이 부족하면 백업 안내를 표시합니다.

## AI와 문서

- 입력한 설계안과 생성 요청은 선택한 AI 제공자로 직접 전송됩니다. 사용량·요금은 해당 API 계정 조건에 따릅니다.
- API 키를 기억할지는 사용자가 선택합니다. 공용 컴퓨터에서는 저장하지 않는 것을 권장합니다.
- 자료 생성은 AI 결과이므로 성취기준·내용·시간 배분을 확인하세요. 문서 속 성취기준을 보존하며 원문에 없는 코드를 만들지 않도록 지시합니다.
- 스캔 PDF에는 텍스트가 없을 수 있습니다. 이 경우 원문 텍스트를 붙여넣어 주세요.
- PDF.js와 PptxGenJS는 필요할 때 CDN에서 로드합니다. 학교 네트워크가 CDN/API를 차단하면 해당 기능을 사용할 수 없습니다.
- 표시하는 생성 문서와 가져온 HTML은 허용 요소만 남겨 정제합니다.

## 복습 및 캘린더

- 복습 기본값: 기능 연습 최소 5일 간격, 최초 학습 포함 3회. 교사가 변경할 수 있습니다. 모든 학생에게 적용되는 고정된 학습 법칙을 뜻하지 않습니다.
- 실제 차시 날짜와 여러 차시 활동의 마지막 날짜를 기준으로 계산합니다. 동일 날짜의 중복 연습은 한 번으로 집계합니다.
- .ics는 전날 준비 일정과 `VALARM`을 포함하며, 시간은 한국 시간 기준입니다. 캘린더 앱의 알림 허용을 별도로 확인하세요.
- 내보내기는 구독·실시간 동기화가 아닙니다. 변경 후 다시 가져올 때 이전 일정 중복을 확인하세요. 다음 단원 권장 메모는 캘린더에 자동 등록되지 않습니다.

## 개발과 검증

빌드 없이 GitHub Pages에서 실행됩니다. `python -m http.server 8765`로 로컬 실행할 수 있습니다.

```sh
node --test tests/core.test.js
```

- `core.js`: 날짜, 작업 스키마, 복습 계산, 캘린더 생성
- `app.js`: 저장·화면·AI·파일 처리
- `generation.js`: 기존의 상세 수업 프롬프트와 PPT 생성
- `runner.js`: 수업 진행 및 타이머
- `events.js`: UI 이벤트 연결
- `styles.css`: 반응형 UI, 테마, 접근성
