# 수업 실행 도우미

개념기반 탐구수업(CBI)·IB PYP 단원 설계안을 올리면, 학습과학에 근거한 **인출·형성평가 일정**을 계산하고 **차시별 수업 자료**(교수학습 과정안·활동지·배움공책 가이드·PPT)를 생성하며, **구글캘린더 알림**까지 내보내는 웹앱입니다.

[PYP 탐구 단원 설계 도우미](https://knightayj52.github.io/PYP-Planner/)의 후속 도구입니다 — 설계 도우미가 만든 단원을, 이 도구가 실행으로 옮깁니다.

## 시작하기

1. **API 키 준비** — 이 앱은 사용자의 Gemini API 키로 작동합니다(BYOK). [Google AI Studio](https://aistudio.google.com/apikey)에서 무료로 발급받으세요. 앱의 "연결 확인" 버튼으로 작동 여부를 먼저 확인할 수 있습니다.
2. **설계안 올리기** — PYP-Planner에서 만든 PDF를 그대로 올리거나, 단원 설계표 본문을 붙여넣습니다. 단원 시작일과 수업 요일, 휴업일을 입력합니다.
3. **분석 → 검토** — 앱이 설계안에서 지식 구조(학생이 남겨야 할 지식, 예상 오개념, 선수지식 연결)를 추출합니다. 화면의 "용어 안내"를 펼치면 처음 보는 표기를 설명해 줍니다.
4. **인출 일정** — 언제 무엇을 다시 꺼내야 하는지 날짜 위에 배치됩니다. 각 시점에서 형성평가 문항을 바로 생성할 수 있습니다.
5. **자료 생성** — 차시별로 과정안·활동지·배움공책 가이드를 만듭니다. 화면에서 직접 고칠 수 있고, 인쇄하거나 한글·워드 파일로 저장하거나, 서식째 복사해 구글 문서에 붙일 수 있습니다. PPT는 파일로 내려받거나, "PPT 개요 복사"로 NotebookLM·감마에 넘겨 고품질 슬라이드를 만들 수 있습니다.
6. **캘린더** — .ics 파일을 내려받아 구글캘린더에서 [설정 → 가져오기]로 등록하면, 각 인출 **전날 저녁 7시**에 문항이 담긴 준비 알림이 옵니다.

## 자주 묻는 것

- **진도가 밀렸어요** — ② 화면에서 차시 날짜만 고치면 전체 일정이 자동으로 다시 계산됩니다. .ics를 다시 내려받아 등록하되, 구글캘린더에서 이전 일정을 먼저 삭제하세요.
- **내 데이터는 어디에 저장되나요** — 전부 이 브라우저 안에만 있습니다. 키와 작업 내용은 어떤 서버로도 전송되지 않습니다(AI 호출 제외). 다른 기기로 옮기려면 ⑤의 "작업 상태 저장"으로 파일을 내려받아 옮기세요.
- **비용이 드나요** — 앱 자체는 무료입니다. Gemini API는 무료 할당량 안에서는 비용이 없고, 사용량은 Google AI Studio에서 확인할 수 있습니다.
